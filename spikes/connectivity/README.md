## `media` — эхо-сервер на pion

Браузер шлёт видео (тестовый canvas или камера), сервер возвращает его обратно, страница показывает отправленное и вернувшееся.

```powershell
./media.exe -mode=udp        # http://localhost:17777/
./media.exe -mode=tcp
./media.exe -mode=turn-tcp
```

Откройте `http://localhost:17777/`, нажмите **Start echo**. Через 15 секунд в блоке под видео появится JSON с результатом (`window.__result`). Параметры страницы: `?auto=1` — старт без клика, `&duration=15` — секунд измерения, `&camera=1` — камера вместо тестового узора (на `localhost` и по HTTPS), `&relay=0` — в `turn-tcp` не ограничиваться relay-кандидатами.

### Режимы (`-mode`)

| Режим | Что делает сервер | Что делает браузер |
|-------|-------------------|--------------------|
| `udp` | ICE UDP mux: один UDP-порт `-media-port` | обычный ICE |
| `tcp` | только passive ICE-TCP на одном TCP-порту `-media-port`, UDP-сокетов нет вообще | подключается сам (активный TCP) |
| `turn-tcp` | встроенный TURN (pion/turn) на TCP `-media-port`; relay-порты UDP `-media-port+1…+50` | `iceTransportPolicy: "relay"`, `turn:<host>:<порт>?transport=tcp` |

### Флаги

| Флаг | По умолчанию | Назначение |
|------|--------------|------------|
| `-http` | `:17777` | адрес HTTP(S): страница, `/ws` (сигнализация), `/headers`, `/config`, `/stats` |
| `-mode` | `udp` | `udp` / `tcp` / `turn-tcp` |
| `-media-port` | `17778` | порт медиа (UDP mux, ICE-TCP или TURN/TCP) |
| `-advertise` | пусто | `хост:порт` внешнего проброса или туннеля; добавляется в ответ как ещё один host-кандидат (хост-имя сервер резолвит сам). Нужен, когда внешний порт ≠ локальному |
| `-public-ip` | пусто | только `turn-tcp`: внешний IP как адрес relay |
| `-tls` | выкл. | HTTPS/WSS на том же порту; самоподписанный сертификат ECDSA P-256 генерируется при старте в памяти (SAN: `localhost`, `127.0.0.1`, все IPv4 интерфейсов), на диск не пишется, действует 7 суток |
| `-tls-host` | пусто | дополнительный IP или имя в SAN (внешний адрес) |

Порты по умолчанию 17777/17778, чтобы не конфликтовать с основным приложением (7777/7778).

### Эндпоинты

- `GET /headers` — JSON: адрес, с которого пришло соединение (`remoteAddr`), `Host`, все заголовки запроса, `tls`, и `currentIsLoopback` — как решила бы текущая `isLoopback` из `internal/httpapi/respond.go`. Нужен, чтобы увидеть, что добавляет туннель.
- `GET /stats` — байты RTP на входе и выходе.
- `WS /ws` — сигнализация: `offer` → `answer` (без trickle: страница ждёт конца сбора кандидатов), `ping` → `pong` (RTT WebSocket).

### Самоподписанный сертификат и камера с телефона

`getUserMedia` работает только в secure context. Для внешних сценариев запускайте с `-tls` (и `-tls-host <внешний IP или имя>`), откройте `https://…`, примите предупреждение браузера («Дополнительно → Перейти на сайт»). WebSocket (`wss://`) после этого работает на той же странице.

## `tls` — Let's Encrypt через autocert

```powershell
./tls.exe -domain 203-0-113-5.sslip.io -cache C:\acme-cache -staging   # сначала staging
./tls.exe -domain 203-0-113-5.sslip.io -cache C:\acme-cache            # затем боевой CA
```

Без `-domain` и `-cache` программа **ничего не запускает** и выходит с кодом 2. Нужны порты 80 (HTTP-01) и 443 (HTTPS, он же TLS-ALPN-01), доступные из интернета. Кэш сертификатов — обязательный флаг: без него каждый запуск заказывает сертификат заново и упирается в лимиты. Ключи в кэше — секретные данные, не коммитьте.

Подробности и пошаговый сценарий — в REPORT.md, сценарий (д).
