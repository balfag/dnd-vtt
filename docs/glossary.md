# Глоссарий

Единые термины для документации (RU) и кода (EN). Если нужного термина нет — добавь его сюда в той же ветке, где он впервые используется.

| RU | EN (код) | Значение |
|----|----------|----------|
| Мастер | GM (`RoleGM`) | Ведущий, владелец установки |
| Игрок | Player (`RolePlayer`) | Участник кампании с ролью `player` |
| Аккаунт | Account | Логин и пароль, локальные для установки мастера |
| Участник | Player | Аккаунт в конкретной кампании: имя, цвет, роль, персонаж |
| Наблюдатель | Spectator | Только просмотр (позже) |
| Кампания | Campaign | Верхний контейнер: сцены, персонажи, вики, ассеты |
| Игровая сессия | Game session | Одна игровая встреча в кампании: от «Начать игру» до «Завершить игру» |
| Ссылка на игру | Game link | `/play/<token>`: вход и регистрация игроков в текущую игровую сессию |
| Сессия входа | Login session | Вход аккаунта на одном устройстве (cookie `dndvtt_session`) |
| Соединение | Connection | Одно WebSocket-подключение вкладки |
| Сброс пароля | Password reset | Одноразовая ссылка `/reset/<token>`, которую выдаёт мастер |
| Сцена | Scene | Одна «карта» стола: фон, сетка, слои, фишки |
| Активная сцена | Active scene | Сцена, которую сейчас видят игроки |
| Слой | Layer | `map` (фон), `tokens` (фишки), `gm` (видно только мастеру), `drawings` |
| Фишка / токен | Token | Объект на сцене, может быть привязан к персонажу или актёру |
| Актёр | Actor | Игровая сущность с характеристиками (персонаж игрока, NPC, монстр) |
| Персонаж | Character | Актёр, которым управляет игрок; имеет лист персонажа |
| Лист персонажа | Character sheet | UI и данные актёра по правилам 5e |
| Сетка | Grid | `square` или `hex`, размер клетки в пикселях и футах |
| Туман войны | Fog of war | Маска, скрывающая части сцены от игроков |
| Шаблон области | Area template | Конус, сфера, линия, куб для заклинаний |
| Линейка | Ruler | Измерение расстояния по сетке |
| Пинг | Ping | Временная метка-указатель на сцене |
| Инициатива | Initiative / Combat tracker | Очерёдность ходов в бою |
| Бросок | Roll | Результат броска кубиков по формуле (`2d6+3`) |
| Видимость броска | Roll visibility | `public`, `gm` (видно мастеру), `self` (видно себе), `blind` (видит только мастер, игрок не видит результат) |
| Чат | Chat | Текстовые сообщения и лог бросков |
| Ассет | Asset | Загруженный файл: изображение карты, токена, аудио |
| Вики | Wiki | Страницы мастера в стиле Notion |
| Страница | Page | Документ вики, блочное содержимое |
| База данных (вики) | Database | Коллекция страниц-записей с типизированными свойствами |
| Свойство | Property | Поле записи базы: text, number, select, multi-select, relation, link |
| Вид | View | Представление базы: таблица, карточки, с фильтрами и сортировкой |
| Упоминание | Mention | `@`-ссылка на сцену, фишку, актёра, страницу или запись SRD |
| Раздаточный материал | Handout | Изображение или текст, показанный игрокам мастером |
| Комната (голос) | Room | Голосовая и видео-конференция игровой сессии |
| SFU | SFU (Selective Forwarding Unit) | Сервер, пересылающий медиапотоки участникам |
| Туннель | Tunnel | Внешний сервис, дающий публичный адрес без проброса портов |
| SRD | SRD 5.2 | System Reference Document 5.2, открытый (CC-BY-4.0) свод правил 5e 2024 |
| Компендиум | Compendium | Встроенная справочная база SRD: заклинания, монстры, предметы |
| Homebrew | Homebrew | Контент, созданный пользователем (черты, заклинания, предметы, классы…), в той же схеме, что SRD |
| Пакет контента | Content pack | Набор записей правил (SRD или homebrew) или ассетов с манифестом |
| Движок правил | Rules engine | Код, интерпретирующий записи контента: подсчёты, создание персонажа, применение эффектов |
| Зона тумана | Fog region | Именованный полигон на карте, раскрываемый одним действием |
| Map builder | Map builder | Сборка карты сцены из ассетов с ролями `wall`, `door`, `window`, `obstacle`, `decor` |
| Освещение | Lighting | Источники света и линия видимости по стенам и дверям |
| Личное сообщение | Private message | Сообщение чата, видимое только отправителю и выбранным получателям |
| Тег | Tag | Метка страницы документации для группировки и поиска |
| MCP-сервер | MCP server | Интерфейс Model Context Protocol для ИИ-ассистента мастера |
| Общая библиотека | Content library | Публичный GitHub-репозиторий пакетов контента под CC-BY-4.0 или CC0 |
| Приветственный экран | Welcome screen | Экран первого запуска с motion design о приложении и системах |
