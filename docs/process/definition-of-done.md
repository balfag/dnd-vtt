# Definition of Done

Задача считается готовой, когда выполнено всё применимое ниже.

## Код
- [ ] Соответствует спецификации в `docs/` (или спека обновлена в этом же PR).
- [ ] Права и видимость проверяются на сервере.
- [ ] Нет захардкоженных строк UI, ключи есть в `ru.json` и `en.json`.
- [ ] Нет новых зависимостей с CGO или с несовместимой лицензией.
- [ ] Нет секретов и отладочного мусора.

## Проверки (команды появятся в M0, до этого — только проверка документации)
- [ ] `go vet ./...` и `golangci-lint run`
- [ ] `go test ./...`
- [ ] `pnpm -C web lint`
- [ ] `pnpm -C web test`
- [ ] `pnpm -C web build` и `go build ./cmd/dndvtt`
- [ ] Ручная проверка в браузере (для UI): мастер + минимум одна вкладка игрока.

## Документация
- [ ] Обновлены затронутые документы `docs/systems/*`, `docs/architecture/*`.
- [ ] Новое архитектурное решение оформлено как ADR.
- [ ] Новые термины добавлены в `docs/glossary.md`.
- [ ] Изменения протокола отражены в `docs/architecture/protocol.md`.
- [ ] Изменения схемы БД — новая миграция и правка `docs/architecture/data-model.md`.

## PR
- [ ] Заголовок в формате Conventional Commits, `Closes #N` в описании.
- [ ] Заполнен шаблон, описан способ проверки.
- [ ] Ветка актуальна относительно `main`.
