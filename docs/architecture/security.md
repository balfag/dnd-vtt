# Безопасность и доступ

> Статус: `draft`

## Модель угроз (кратко)

Сервер открыт в интернет на домашнем ПК мастера. Угрозы:
1. Посторонний нашёл адрес и пытается войти. → Вход только по инвайту.
2. Игрок пытается увидеть секреты мастера (GM-слой, вики, скрытые броски). → Фильтрация на сервере.
3. Игрок пытается сломать состояние или ПК мастера (загрузка файлов, path traversal, флуд). → Валидация, лимиты, изоляция путей.
4. Перехват трафика. → HTTPS/WSS при подключении извне, DTLS-SRTP для медиа (встроено в WebRTC).

## Аутентификация

- **Мастер** входит с `localhost`: при запуске генерируется одноразовая GM-ссылка `http://localhost:7777/?gm=<token>`, которую приложение само открывает в браузере. Запросы к GM-API разрешены только с GM-сессией; дополнительно GM-вход принимается только с loopback-адреса (вход мастера извне — открытый вопрос).
- **Игрок** входит по инвайт-ссылке `https://<host>/join/<invite-token>`:
  1. Сервер проверяет токен (хранится только хеш, учитываются срок и лимит использований).
  2. Игрок вводит имя; создаётся `Player` и сессионный токен (cookie `HttpOnly; Secure; SameSite=Strict`, 32 байта из `crypto/rand`).
  3. Повторный заход с тем же cookie — это тот же игрок.
- Мастер может отозвать инвайт и выгнать игрока (инвалидация сессии и разрыв WS).

## Авторизация

| Ресурс | GM | Player |
|--------|----|--------|
| Сцены: просмотр | все | только активная, без слоя `gm` |
| Фишки: видимость | все | кроме `hidden` и слоя `gm` |
| Фишки: перемещение | все | где он в `owners` и фишка не `locked` |
| Туман | редактирует | видит только раскрытое; маска применяется на сервере (скрытые фишки не отправляются) |
| Броски `gm` / `blind` | видит | `gm`: видит свои; `blind`: не видит результат |
| Вики | полный доступ | **нет доступа** (только handout'ы) |
| Листы | все | свой: чтение и запись; чужие: только публичная часть (имя, портрет) |
| Ассеты | загрузка, удаление | чтение только тех, что используются на видимых сценах и в handout'ах |

## Загрузка файлов

- Загружает только мастер (на старте). Лимит размера (например, 50 МБ на файл).
- Проверка MIME по содержимому, а не по расширению; разрешены изображения (png, jpg, webp, gif) и аудио (позже).
- Имя на диске — sha256, исходное имя только в БД, поэтому path traversal невозможен.
- SVG запрещён (может содержать скрипты) или отдаётся с `Content-Security-Policy: sandbox`.

## Заголовки

CSP без внешних источников (`default-src 'self'`), `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`; разрешения `camera`/`microphone` — только для self.

## Секреты

Ключ TLS, секрет для подписи и токены туннеля хранятся в папке данных с правами только для текущего пользователя и никогда не попадают в репозиторий и логи.
