# Визуальный язык клиента

> Статус: `review`. Правила процесса — [skills/frontend.md](../../skills/frontend.md). Этот документ — общий для всех UI-задач; новые экраны берут токены и принципы отсюда.

## Предмет и задача

Приложение — стол для D&D, за которым мастер и друзья проводят вечер. Экраны входа и экран мастера — двери к этому столу: игрок приходит по ссылке из мессенджера и должен оказаться в игре за несколько секунд, мастер — быстро начать игру и раздать ссылку. Интерфейс тихий и тёмный (за ним сидят часами), а одна выразительная деталь взята из самой игры.

## Палитра

| Токен | Hex | Роль |
|-------|-----|------|
| `--slate` | `#23303A` | фон страницы: сланец при свете лампы |
| `--board` | `#2E3D49` | поля ввода, поднятые поверхности, раскрытая карта |
| `--chalk` | `#ECE7DB` | основной текст, контур карты |
| `--fog` | `#9AA8B3` | второстепенный текст, линии сетки, разделители |
| `--verdigris` | `#4FA58E` | главное действие (патина на меди) |
| `--ink-on-verdigris` | `#10201B` | текст на `--verdigris` |
| `--brass` | `#C9A34E` | фокус клавиатуры, отметки мастера |

Цвета участников — палитра игроков с сервера (`playerColors` в `internal/game`); на фишках и в списках используются как есть.

## Шрифты

- **Alegreya** (засечки) — заголовки и повествовательные фразы: 700 для заголовков, 400 для текста-повествования.
- **Alegreya Sans** — интерфейс: поля, кнопки, подписи, списки; 400 и 500.
- Оба — OFL-1.1, локально через `@fontsource` (кириллица и латиница), без внешних CDN.
- Шкала (px): 14 · 15 · 17 (база) · 18 · 24 · 31 · 40. Межстрочный интервал текста — 1.5, заголовков — 1.1. Длина строки текста — до 70 знаков.

## Раскладка

- **Экраны входа** (`/setup`, `/login`, `/play/<token>`, `/reset/<token>`): одна колонка формы шириной до 26rem, выровнена **по левому краю** с отступом `clamp(0px, 8vw, 120px)`; справа — иллюстрация карты (см. ниже). Ниже 720px иллюстрация скрыта, форма на всю ширину с полями 16px.
- **Экран мастера:** таблица-реестр, а не карточки: строки кампаний с тонкими разделителями, действие строки справа; активная игра — полоса над списком со ссылкой и действиями.

## Выразительная деталь: комната, раскрытая из тумана

Фон экранов входа — ровный «туман» (`--slate`). Справа из тумана раскрыта одна комната подземелья: внутри видна шестиугольная сетка и три фишки цветами игроков, по контуру — тонкая линия `--chalk`. Это и есть «туман войны» — главный жест игры, а не декор. Остальной интерфейс сдержан.

- SVG, `viewBox="0 0 1200 800"`, `preserveAspectRatio="xMidYMid slice"`, `aria-hidden`.
- Раскрытие — `clipPath` с **самим** контуром комнаты внутри (`<path d=…>`), **без** `<use>` внутри `clipPath`, без `mask` и фильтров: такие варианты не отрисовываются надёжно (проверено на прототипе).
- Анимация одна: туман над картой тает за 1.4 с после загрузки. Базовое состояние слоя тумана — **прозрачный** (`opacity: 0`), анимация идёт `from { opacity: 1 }` с `animation-fill-mode: backwards`. При `prefers-reduced-motion: reduce` анимации нет и карта видна сразу.

## Принципы

1. **Стол — герой.** Смелость тратится в одном месте (комната из тумана); остальное — тихо и дисциплинированно.
2. **Кнопки — глаголы, одно действие — одно имя:** «Войти в игру», «Начать игру», «Скопировать ссылку», «Завершить игру». Тост после действия называет то же действие.
3. **Ошибка говорит, что случилось и что сделать**, без извинений: «Ссылка больше не работает. Попросите мастера прислать новую».
4. **Структура несёт смысл:** разделители и линии — только между сущностями; никаких меток-«бровей» капслоком над заголовками, номеров `01/02`, моно-шрифта для подписей, стрелок «→» в кнопках.
5. **Форма:** скругление 6px только у полей и кнопок; без теней и градиентов.
6. **Доступность — пол качества:** видимый фокус `2px solid var(--brass)` со смещением 2px; контраст текста не ниже WCAG AA; всё доступно с клавиатуры; `prefers-reduced-motion` уважается; адаптивность до 360px.
7. **Тексты** — через i18n, простым языком пользователя: «логин», «ссылка на игру», а не «токен сессии».
