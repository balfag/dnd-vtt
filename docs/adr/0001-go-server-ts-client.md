# ADR-0001: Go-сервер + TypeScript-клиент в одном бинарнике

- **Статус:** accepted
- **Дата:** 2026-10-15

## Контекст
Мастер должен скачать и запустить одно приложение, а игроки — зайти из браузера без установки. Нужен встроенный WebRTC SFU на 6–8 камер. Основная платформа мастера — Windows.

## Решение
- Сервер на **Go**, собирается в один статический бинарник (`CGO_ENABLED=0`).
- Клиент — **TypeScript + React + Vite**, собирается в `web/dist` и встраивается через `go:embed`.
- Мастер тоже пользуется браузерным клиентом (на `localhost`); нативное окно не делаем, только иконка в трее.

## Рассмотренные альтернативы
- **Всё на TypeScript (Node/Bun):** один язык, но для SFU пришлось бы тащить LiveKit как отдельный бинарник или mediasoup (нативная сборка C++ на Windows), упаковка в один файл сложнее.
- **Tauri (Rust):** лёгкое нативное окно, но WebRTC SFU на Rust менее зрелый, Rust сложнее поддерживать.

## Последствия
- Два языка в репозитории: нужны два набора линтеров и тестов.
- Типы протокола дублируются в Go и TS: нужна генерация или тест-сверка (решается в M0).
- Кросс-компиляция под Windows, Linux и macOS тривиальна.
