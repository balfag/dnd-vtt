# ADR-0006: вики только для мастера, без совместного редактирования

- **Статус:** accepted
- **Дата:** 2026-10-15

## Контекст
Вики в стиле Notion нужна мастеру для ведения кампании. Пользователь подтвердил: совместное редактирование не нужно, доступ только у мастера; важны базы данных и ссылки на игровые объекты.

## Решение
- Вики доступна только роли GM. Игрокам контент передаётся только через handout'ы.
- Без CRDT/OT. Документ страницы хранится как ProseMirror JSON, сохраняется целиком с проверкой версии (оптимистичная блокировка по `updated_at`).
- Редактор — TipTap.
- Базы данных — собственная реализация поверх таблиц `wiki_*` (свойства в JSON).

## Рассмотренные альтернативы
- **Yjs (CRDT):** нужен только для совместного редактирования, добавляет сложность хранения и синхронизации.
- **Markdown-файлы на диске:** просто, но плохо ложится на базы данных, свойства и упоминания.

## Последствия
- Если в будущем понадобятся заметки игроков, это будет отдельная функция (новый ADR), а не расширение вики.
