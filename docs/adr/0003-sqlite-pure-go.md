# ADR-0003: SQLite без CGO

- **Статус:** accepted
- **Дата:** 2026-10-15

## Контекст
Нужна встраиваемая надёжная БД без отдельного процесса и с сохранением сборки без CGO.

## Решение
- **SQLite** через драйвер **modernc.org/sqlite** (чистый Go).
- Режим WAL, `foreign_keys=ON`, одна БД на установку.
- Файлы ассетов — на диске, адресация по sha256.
- Миграции — нумерованные `.sql`-файлы, встроенные в бинарник, только вперёд.

## Рассмотренные альтернативы
- **mattn/go-sqlite3:** быстрее, но требует CGO и gcc на Windows.
- **bbolt/badger (KV):** нет SQL, FTS и связей, которые нужны для вики и баз данных.
- **Файлы JSON:** нет транзакций, плохо для конкурентных изменений.

## Последствия
- modernc немного медленнее CGO-варианта, для нашей нагрузки (8 человек) это несущественно.
- Полнотекстовый поиск — через FTS5 (поддерживается modernc).
