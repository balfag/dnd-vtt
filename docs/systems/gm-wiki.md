# Система 4: вики мастера (в стиле Notion)

> Статус: `review`. Майлстоун: M3. Решение: [ADR-0006](../adr/0006-wiki-gm-only-no-crdt.md)

## Цель

Место, где мастер ведёт всю кампанию: сюжет, NPC, локации, квесты, итоги сессий. Связано с игрой: из страницы можно открыть сцену, выделить фишку, показать игрокам картинку.

## Ограничения скоупа

- **Только мастер.** Игроки не имеют доступа к вики. Показать что-то игрокам можно только через handout.
- **Без совместного редактирования.** Один редактор (мастер), CRDT не используется. Сохранение — автосейв с дебаунсом; при открытии в двух вкладках работает защита по версии (`updated_at`), вторая вкладка получает предупреждение о конфликте.

## Страницы

- Дерево страниц с вложенностью, drag-and-drop для изменения порядка и родителя.
- Иконка (эмодзи) и обложка (изображение) страницы.
- Блочный редактор (TipTap): заголовки, списки, чек-листы, цитаты, callout, разделитель, код, таблица (простая), изображение, toggle (сворачиваемый блок).
- Команда `/` для вставки блоков, markdown-шорткаты (`#`, `-`, `[]`).
- Корзина: удалённые страницы восстанавливаются в течение N дней.
- Поиск по заголовкам и тексту (SQLite FTS5).
- **Теги:** у страницы любое число тегов; фильтр и поиск по тегам, список страниц тега, переименование и слияние тегов.

## Базы данных

- Страница может содержать **базу данных** — коллекцию страниц-записей с общими свойствами.
- Типы свойств: `text`, `number`, `select`, `multi_select`, `checkbox`, `date`, `url`, `relation` (ссылка на записи другой базы), `game_link` (ссылка на сцену, актёра или фишку).
- Каждая запись — полноценная страница с содержимым.
- **Виды:** таблица и карточки (галерея); у вида есть свои фильтры, сортировки и набор видимых свойств. Несколько видов на базу.
- Шаблоны баз «из коробки»: NPC, Локации, Квесты, Сессии, Предметы.

## Связь с игрой (упоминания)

- `@` в тексте открывает поиск по **любым объектам**: страницам вики, сценам, актёрам (персонажам и NPC), фишкам активной сцены, записям компендиума SRD и homebrew (заклинания, монстры, предметы, черты), ассетам.
- Клик по упоминанию:
  - сцена → открыть у мастера (с кнопкой «сделать активной»);
  - актёр → открыть лист;
  - фишка → перейти к ней на сцене и выделить;
  - запись SRD → всплывающая карточка.
- Обратные ссылки: на странице видно, где она упомянута (backlinks).
- Инлайн-бросок: запись `[[2d6+3]]` в тексте становится кнопкой броска (видимость `gm` по умолчанию).

## Handout'ы

- Кнопка «Показать игрокам» на изображении или выделенном блоке: игроки получают модальное окно с этим содержимым. Сама страница остаётся недоступной.
- Можно показать выбранным игрокам.
- Показанное сохраняется в чате как сообщение `handout`, чтобы игроки могли открыть его снова.
