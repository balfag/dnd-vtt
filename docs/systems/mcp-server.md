# Система 5: MCP-сервер для ИИ-ассистента мастера

> Статус: `draft`. Майлстоун: M8. Решение: [ADR-0010](../adr/0010-local-mcp-server.md)

## Цель

ИИ-ассистент мастера (Claude Desktop и другие клиенты MCP на его ПК) может делать всё, что делает мастер: готовить кампанию, сцены и NPC, вести вики, управлять игрой. Мастер пишет «расставь гоблинов у входа в пещеру и спрячь их от игроков» — ассистент делает это через инструменты приложения.

## Подключение

- В настройках мастер нажимает «Подключить ИИ-ассистента»: создаётся токен MCP и показывается готовый фрагмент конфигурации для клиента (команда `dndvtt mcp` и переменная окружения с токеном).
- `dndvtt mcp` — режим stdio: процесс подключается к работающему приложению мастера по loopback. Альтернатива — streamable HTTP на `http://localhost:<порт>/mcp`.
- Токен можно отозвать; отзыв обрывает текущие подключения.

## Возможности (инструменты MCP)

Группы инструментов совпадают с системами; каждая появляется вместе со своей системой:

| Группа | Примеры |
|--------|---------|
| Кампании и игры | список кампаний, начать и завершить игру, ссылка на игру, участники |
| Сцены и карты | создать сцену, загрузить карту, расставить и спрятать фишки, туман войны, освещение |
| Документация | найти страницу, создать или дополнить страницу, теги, ссылки на объекты |
| Персонажи и NPC | создать NPC по правилам, изменить лист, homebrew-записи |
| Чат и кубики | бросок от имени мастера, сообщение в чат, handout игрокам |

Ресурсы MCP (только чтение): текущая сцена, список участников, страницы вики, компендиум SRD.

## Безопасность

- Только loopback; права — как у мастера; действия помечаются «сделано ассистентом».
- Необратимые операции (удаление кампании, сцены, участника, страницы) требуют подтверждения мастера в интерфейсе приложения.

## Открытые вопросы

- Нужен ли журнал действий ассистента с возможностью отменить последнее действие?
- Нужны ли подсказки (prompts MCP) — готовые сценарии вроде «подготовь сессию по заметкам»?
