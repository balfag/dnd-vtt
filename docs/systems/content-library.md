# Общая библиотека контента

> Статус: `draft`. Майлстоун: M9. Решение: [ADR-0011](../adr/0011-community-content-library-github.md)

## Цель

Мастера делятся своими картами, ассетами, наборами фишек, звуками и homebrew-пакетами через общий публичный GitHub-репозиторий проекта, а любой мастер находит и скачивает их прямо в приложении.

## Что можно публиковать

- Только **свою** работу под **CC-BY-4.0** или **CC0**; лицензия указывается в манифесте и подтверждается при публикации.
- Нельзя: чужие работы без права на перераспределение, тексты и иллюстрации закрытых книг, homebrew, пересказывающий закрытые книги.
- Каждый пакет проходит ревью мейнтейнеров (pull request в репозиторий библиотеки).

## В приложении

- **Поиск и скачивание** — без входа в GitHub: поиск по названию, тегам, типу (карта, ассет, фишки, звук, homebrew); превью; «Добавить в кампанию».
- **Публикация** — после подключения GitHub (OAuth device flow): мастер выбирает ассеты кампании, заполняет название, теги, лицензию, подтверждает авторство; приложение создаёт pull request и показывает его статус.
- Скачанный пакет хранится локально; повторное скачивание не нужно, библиотека работает и без интернета для уже скачанного.

## Открытые вопросы

- Лимиты размера пакета и способ хранения крупных файлов (Git LFS или GitHub Releases).
- Кто мейнтейнеры библиотеки и где правила публикации (отдельный `CONTRIBUTING.md` репозитория библиотеки).
- Атрибуция автора в интерфейсе при использовании ассета.
